## Use and changes in Polytype

Polytype selects entries for typing practice and displays the available definitions,
pronunciations, and parts of speech. The dictionary editor can add entries and modify
words, IPA, parts of speech, and definitions in the local database. An edited copy may
therefore differ from the upstream release.

If you redistribute the data, keep the source credit and license links with it.
